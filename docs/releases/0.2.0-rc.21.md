# 0.2.0-rc.21 — Hue BLE Brightness Transitions & Worker `BrightnessRelative` Support

**Status:** Release candidate whose signed router bundle completed live router acceptance (`bootstrapInSync: true`, `healthy: true`) on the existing personal installation on 24 November 2026.  
**Router package ID:** `0.2.0-rc.21` · **Signed release sequence:** `21` · **Code commit:** `9ee27ce`

## Changes Since 0.2.0-rc.20 and Verification

- **Router BLE lamp & controller transition improvements (`hue_agent/lamp.py`, `hue_agent/agent.py`, `tests/test_core.py`, `tests/test_agent.py`, `tests/test_cloud_context.py`):**
  - Updated `Lamp.set_raw()` to skip redundant `POWER` writes when changing brightness on an already-on bulb, skip no-op writes when the observed state already matches the target, and perform a single bounded brightness re-write if turning the bulb from `OFF` to `ON` snaps back to its remembered brightness before converging.
  - Updated `Controller` in `hue_agent/agent.py` to wait briefly (up to `ready_wait_limit` within the remaining command deadline) when `monitor()` is actively reconnecting instead of immediately returning `BLE_OFFLINE`, and to preserve a healthy encrypted BLE connection when `STATE_CHANGED_DURING_COMMAND` occurs without transport disconnection.
- **Cloudflare Worker Google Home dimming & uncertain-outcome sync (`cloud/src/google-home.ts`, `cloud/src/oauth-store.ts`, `cloud/test/google-home.test.ts`, `cloud/test/queued-execution.test.ts`):**
  - Added `action.devices.commands.BrightnessRelative` support (`brightnessRelativePercent` and `brightnessRelativeWeight`) with strict parameter validation and clamping to `0..100`.
  - Collapsed `OnOff(true)` paired with `BrightnessAbsolute(X > 0)` in the same `EXECUTE` batch into a single `{ brightness: X }` write.
  - Added best-effort read-only state query and HomeGraph report enqueueing in `AuthStore.drainCommand()` when a command ends in `OUTCOME_UNKNOWN` and no more writes remain pending.
- **Live router acceptance & local test gates (`0.2.0-rc.21`):**
  - Local gates on commit `9ee27ce` passed `21/21` agent tests (`tests/test_agent.py`), `94/94` portable Python tests (`tools/run_portable_tests.py`: `failures: 0, errors: 0, skipped: 0`), `15/15` Cloudflare Worker test files (`73/73` `vitest` tests + `tsc --noEmit`), and `tools/check_publication.py` (`errors: []`, `ok: true`).
  - Deployed `keenetic-hue-0.2.0-rc.21.huerel` to the router with `bootstrapInSync: true`, verified `huectl status --json` and `huectl health --live --json` (`healthy: true`, `releaseId: "0.2.0-rc.21"`, `bootstrapReleaseId: "0.2.0-rc.21"`, `agent: "running"`, `tunnel: "ready"`, `manager: "running"`, `localApi: "ready"`, `ble: "ready"`), and verified live brightness transitions (`40` → `80` → `20` → `off`, all `status: "verified"` without `OUTCOME_UNKNOWN`).
