## Changes Since 0.2.0-rc.21 and Verification

- **Router journal & event-loop stall elimination (`hue_agent/journal.py`, `hue_agent/agent.py`, `tests/test_agent.py`, `tests/test_query_capacity.py`):**
  - Kept read-only `query` deduplication, conflict detection, and sequence tracking in memory (30 s / 64-entry bound, preserving `COMMAND_ID_CONFLICT` and `STALE_SEQUENCE` across `query` and `set`) so read-only queries never issue USB flash `fsync()` calls.
  - Switched `commands.sqlite` to `PRAGMA journal_mode=PERSIST` + `PRAGMA synchronous=FULL` + `PRAGMA journal_size_limit=65536` (compatible with `hue_admin/agent_storage.py` backup/recovery without `-wal`/`-shm` sidecars) and offloaded all SQLite writes to a dedicated FIFO single-worker thread.
  - Added fast RAM-first `reserve_fast()` / `lookup_fast()` for `Controller.execute()` with ordered background SQLite persistence (`schedule_finish()` / `finish_async()`), eliminating multi-second USB flash blocking on `set` commands and `/v1/session`.
  - Preserved healthy BLE readiness when a pre-BLE deadline expires before BLE I/O begins, and added sanitized `command_failed` logging.
- **Router fast BLE reconnect & tunnel deadline alignment (`hue_agent/bumble_io.py`, `hue_agent/tunnel_api.py`, `tests/test_agent.py`, `tests/test_tunnel_api.py`):**
  - Logged sanitized `ble_disconnected` reason codes and reused the open USB HCI device for fast BLE-only reconnects after clean peer disconnections, falling back to full USB transport close/reopen on error.
  - Raised `TunnelController` expiry ceiling to `+9 s` to match `7 s` `set` command lifetimes.
- **Cloudflare Worker session & queue resilience (`cloud/src/protocol.ts`, `cloud/src/relay.ts`, `cloud/src/command-queue.ts`, `cloud/src/oauth-store.ts`, `cloud/test/*.ts`):**
  - Extended `set` wire TTL to `7 s` (`8 s` fetch timeout) while keeping `query` at `5 s` (`6 s` timeout).
  - Relaxed `/v1/session` round-trip bound to `2.5 s` (still subtracting full measured RTT from `expiresAt`) with a single retry on transient slowness or `5xx`.
  - Extended durable queue job lifetime to `25 s` and added a single `1.5 s` backoff retry on confirmed pre-delivery `CLOCK_UNCERTAIN` / `BLE_OFFLINE` responses (automatically dropped if superseded by a newer waiting brightness command; `OUTCOME_UNKNOWN` is never retried).
- **Live router acceptance & local test gates (`0.2.0-rc.24`):**
  - Local gates on commit `cc5daf8` passed `57/57` targeted tests (`tests/test_agent.py`, `tests/test_core.py`, `tests/test_tunnel_api.py`, `tests/test_query_capacity.py`, `tests/test_journal_capacity.py`, `tests/test_sqlite_crash_recovery.py`; `2` POSIX root tests skipped on Windows), `96/96` portable Python tests (`tools/run_portable_tests.py`: `failures: 0, errors: 0, skipped: 0`), `15/15` Cloudflare Worker test files (`76/76` `vitest` tests + `tsc --noEmit`), and `tools/check_publication.py` (`errors: []`, `ok: true`).
  - Deployed `keenetic-hue-0.2.0-rc.24.huerel` to the router with `bootstrapInSync: true`, verified `huectl status --json` and `huectl health --live --json` (`healthy: true`, `releaseId: "0.2.0-rc.24"`, `bootstrapReleaseId: "0.2.0-rc.24"`, `agent: "running"`, `tunnel: "ready"`, `manager: "running"`, `localApi: "ready"`, `ble: "ready"`), verified `5/5` consecutive cloud queries (`625–890 ms`, `status: "verified"`), `3/3` consecutive cloud `set` commands (`1,282–1,313 ms`, `status: "verified"`), `/admin/report-check` (`reported: true, matched: true`), and `commands.sqlite` (`PRAGMA quick_check: ok`, `query_rows: 0`, all `3` `set` rows persisted).
