# 0.2.0-rc.17 — BLE Retry Log Coalescing, Tunnel Stdio Isolation, and Automatic Release/Backup Pruning

**Status:** Release candidate whose signed router bundle completed live router acceptance (`bootstrapInSync: true`, `healthy: true`) on the existing personal installation on 14 November 2026.  
**Router package ID:** `0.2.0-rc.17` · **Signed release sequence:** `17` · **Code commit:** `2c0df72`

## Changes Since 0.2.0-rc.16 and Verification

- **Agent BLE retry log coalescing (`hue_agent/agent.py`):**
  - Updated `Controller.monitor()` to track consecutive `failures` and `last_error`, emitting `ble_retry` only during the first 6 attempts, on error-type changes, or once every 80 attempts (recording `attempts`), and emitting `recoveredAfter` on `ble_ready` when recovering after errors. Prevents repetitive `TimeoutError` flooding in `agent.log` when the Hue lamp is physically switched off.
- **Tunnel stdio isolation (`deploy/component-child.py`):**
  - Redirected child `fd 1` (`stdout`) and `fd 2` (`stderr`) to `os.devnull` before `os.execve` in the `tunnel` branch while preserving `saved_err` to restore `fd 2` if `execve` raises. Prevents `cloudflared` from keeping root-owned `tunnel-bootstrap.log` open or duplicating output outside `data/tunnel.log`.
- **Automatic release and bootstrap backup pruning (`hue_admin/activation.py`, `hue_admin/bootstrap_install.py`):**
  - Added `prune_obsolete_releases(root)` invoked after committed activations in `activate_candidate()` under `install_lock` (requires committed receipts, protects `active.json`, `activation.json`, `installation.json`, `bootstrap.json`, `runtime-repair.json`, and `run/*.json` `releaseId`s, and prunes unreferenced directories across `releases/`, `*-runtime/bin/`, and `*-runtime/agent/code/`).
  - Added `prune_bootstrap_backups(root, keep=2)` at the end of `provision_bootstrap()` to retain the active receipt's `bootstrap-*` backup plus the newest prior directory.
- **Live router acceptance & local test gates (`0.2.0-rc.17`):**
  - Workstation gates passed `91/91` portable Python tests (`566` total in `tests/`, including `141` Windows-skipped native Linux/POSIX/root checks) and `tools/check_publication.py` (`275` files checked).
  - Activated `keenetic-hue-0.2.0-rc.17.huerel` via `/opt/bin/huectl update`, synchronized `root/manager` and pruned obsolete slots/backups via `provision_bootstrap`, `prune_bootstrap_backups`, and `prune_obsolete_releases`, and verified `huectl status --json` and `huectl health --live --json` (`healthy: true`, `releaseId: "0.2.0-rc.17"`, `bootstrapReleaseId: "0.2.0-rc.17"`, `bootstrapInSync: true`) with `cloudflared` `fd/1` and `fd/2` pointing to `/dev/null` and unreferenced releases (`rc.1`–`rc.14`) and legacy logs/scratch backups cleaned up (reclaiming ~`543.7M` on `/opt`, leaving `rc.15`, `rc.16`, and `rc.17`).
