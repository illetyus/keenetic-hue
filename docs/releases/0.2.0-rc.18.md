## Changes Since 0.2.0-rc.17 and Verification

- **Backup password prompt hardening (`hue_admin/cli.py`, `tests/test_admin_cli.py`):**
  - Removed the undocumented `?` branch in `read_backup_password` that generated a password with `secrets.token_urlsafe(24)` and printed it in cleartext to `sys.stderr`, bypassing `getpass` non-echo protection and resolving GitHub CodeQL alert #5 (`py/clear-text-logging-sensitive-data`).
  - Updated `test_backup_password_is_confirmed_and_never_echoed` to verify confirmation via non-echoing `getpass`, assert zero password echo on `stderr`, and confirm `?` is rejected with exit code `1` (`BACKUP_OR_RESTORE_FAILED`).
- **Legacy installer and updater explicit file-mode hardening (`deploy/install.py`, `deploy/update.py`):**
  - Replaced direct `Path.write_bytes`, `Path.write_text`, and `.open('xb')` calls in `install_snapshot()` and `apply_snapshot()` with `_write_private` / `_replace_private` (`os.open` with `O_WRONLY | O_CREAT | O_EXCL | O_NOFOLLOW` and explicit `0o600` mode / `fchmod`), and cleaned up legacy snapshot taint naming (`load_verified_snapshot`), resolving GitHub CodeQL alerts #1–#4 (`py/clear-text-storage-sensitive-data`) without altering `tests/test_security.py` or `tests/test_update.py` contracts.
- **Live router acceptance & local test gates (`0.2.0-rc.18`):**
  - Workstation gates passed `91/91` portable Python tests (`566` total in `tests/`, including `141` Windows-skipped native Linux/POSIX/root checks) and `tools/check_publication.py` (`errors: []`).
  - Activated `keenetic-hue-0.2.0-rc.18.huerel` via `/opt/bin/huectl update`, synchronized `root/manager` and pruned backups/obsolete slots via `provision_bootstrap`, `prune_bootstrap_backups`, and `prune_obsolete_releases`, and verified `huectl status --json` and `huectl health --live --json` (`healthy: true`, `releaseId: "0.2.0-rc.18"`, `bootstrapReleaseId: "0.2.0-rc.18"`, `bootstrapInSync: true`, `tunnel: "ready"`, `localApi: "ready"`, `ble: "ready"`).
