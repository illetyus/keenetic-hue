## Changes Since 0.2.0-rc.18 and Verification

- **Restore transaction SQLite sidecar cleanup (`hue_admin/restore_transaction.py`, `tests/test_restore_transaction.py`):**
  - Added `_unlink_sqlite_sidecars(path)` and invoked it in `recover()` before `atomic_replace(target, source)` so stale `-wal`, `-shm`, and `-journal` sidecars under `root/state/` are unlinked before restoring `state/commands.sqlite` on rollback, preventing SQLite from replaying mismatched journal frames after rollback (`test_failed_health_removes_sqlite_sidecars_on_rollback`).
- **Legacy migration rollback sidecar cleanup (`hue_admin/migration.py`, `tests/test_existing_migration.py`):**
  - Extended `rollback()` cleanup of legacy `agent/state` sidecars to include `commands.sqlite-journal` alongside `-wal`/`-shm` and added `('-wal', '-shm', '-journal')` sidecar cleanup for `root/state/commands.sqlite` (`test_rollback_removes_legacy_journal_and_new_state_sidecars`).
- **Initialization restore quarantine & emptiness guard (`hue_admin/initialize_restore.py`, `tests/test_initialize_restore.py`):**
  - Added `SIDECARS = ('state/commands.sqlite-wal', 'state/commands.sqlite-shm', 'state/commands.sqlite-journal')` to `recover_if_needed()` quarantine and `initialize()` emptiness validation (`INITIALIZE_NOT_EMPTY`) so interrupted initialization restores cannot leave or reuse orphan SQLite sidecars (`test_recovery_quarantines_sqlite_rollback_journal_and_blocks_stale_sidecars`).
- **Live router acceptance & local test gates (`0.2.0-rc.19`):**
  - Workstation gates on commit `ececa49` passed `20/20` targeted regression tests, `91/91` portable Python tests (`569` passing out of `710` discovered in `tests/`, with `141` Windows-skipped native Linux/POSIX/root checks), and `tools/check_publication.py` (`filesChecked: 279`, `errors: []`, `ok: true`).
  - Pre-stopped `0.2.0-rc.18` `tunnel` and `agent` cleanly via `/opt/bin/huectl stop` (`state/agent-runtime.json` transitioned to `phase: "exported"`), activated `keenetic-hue-0.2.0-rc.19.huerel` via `/opt/bin/huectl update`, synchronized `root/manager` and pruned old backups/obsolete slots via `provision_bootstrap`, `prune_bootstrap_backups`, and `prune_obsolete_releases`, and verified `/opt/bin/huectl status --json` and `/opt/bin/huectl health --live --json` (`healthy: true`, `releaseId: "0.2.0-rc.19"`, `bootstrapReleaseId: "0.2.0-rc.19"`, `bootstrapInSync: true`, `tunnel: "ready"`, `localApi: "ready"`, `ble: "ready"`).
