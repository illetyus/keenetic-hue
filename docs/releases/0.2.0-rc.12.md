# 0.2.0-rc.12 — Staged SQLite Recovery and Lifecycle Diagnostics

**Status:** Release candidate that completed live acceptance on the existing
personal installation on 8 November 2026.  
**Router package ID:** `0.2.0-rc.12` · **Signed release sequence:** `12`

## Changes and Live Acceptance

- Fixed a startup deadlock where a hot SQLite rollback journal blocked read-only
  pre-start checkpointing. The original database and journal pair are preserved
  together as opaque root-private (`0700`/`0600`) files before bounded recovery
  runs on a staged copy under the dedicated `hue-agent` (`61001`) principal.
- Preserved command deadlines and the invariant that uncertain physical commands
  (`OUTCOME_UNKNOWN`) are never automatically replayed.
- Added bounded, structured lifecycle and supervisor logs recording the exact
  failed startup stage, supervisor start/TERM/INT/exit events, and child exit
  outcomes without logging secrets, tokens, or raw exception payloads.
- Verified the Ed25519 signature and all 90 payload entries. Dedicated service
  principals, local API/BLE, outbound Tunnel, HomeGraph state parity, and Google
  Home command execution passed. Automatic startup after a full router reboot and
  subsequent Google Home command execution passed with zero manual service starts.
