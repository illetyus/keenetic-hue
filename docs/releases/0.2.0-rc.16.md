# 0.2.0-rc.16 — Agent Lifecycle, Cloud Relay, and Bootstrap Sync Hardening

**Status:** Release candidate whose signed router bundle completed live router acceptance (`bootstrapInSync: true`, `healthy: true`) on the existing personal installation on 11 November 2026. The bundled `cloud/` Worker fixes passed local TypeScript and Vitest gates cleanly; deploying the updated Worker to Cloudflare requires separate `wrangler login` authentication and `wrangler.personal.jsonc` deployment.  
**Router package ID:** `0.2.0-rc.16` · **Signed release sequence:** `16` · **Code commit:** `311c46e`

## Changes Since 0.2.0-rc.15 and Verification

- **Agent runtime, protocol, and supervision (`hue_agent/`, `deploy/`):**
  - Prevented concurrent in-flight `commandId` retries from prematurely returning `OUTCOME_UNKNOWN` by distinguishing pending rows pre-lock while keeping crash-recovery `OUTCOME_UNKNOWN` semantics intact (`agent.py`, `journal.py`).
  - Released the controller lock during reconnect attempts, added fast-fail `BLE_OFFLINE` responses when offline, added an idle `30s` status probe for silent USB drops, guarded `journal.finish` failures, and passed `until` in `Lamp.set_raw` (`agent.py`, `lamp.py`).
  - Preserved Python 3.13 external cancellation (`Task.cancelling()`) in `BleIo.close`, guarded `CloudLink.session` heartbeat failures during teardown, ensured `journal.close()` executes even on close timeouts, added UTC ISO timestamps to `agent.log`, and rejected extreme `expiresAt` values cleanly (`bumble_io.py`, `cloud_link.py`, `__main__.py`, `local_api.py`, `protocol.py`, `tunnel_api.py`).
  - Hardened `deploy/hue-supervise.sh` (monotonic `/proc/uptime` timer, FD closure in sleep/watchdog, `15s` `SIGKILL` fallback), added startup `tunnel.log` rotation in `deploy/component-child.py`, and hardened supervisor orphan recovery / `-I` flags in legacy helpers.
- **Admin CLI, bootstrap sync, and storage (`hue_admin/`, `deploy/huectl-entry.py`):**
  - Allowed `-h`, `--help`, and bare `huectl` invocations to bypass management locks and skip `recover_before_start` without weakening operational admission (`admission.py`, `bootstrap.py`); exited cleanly with code `130` on `KeyboardInterrupt` (`huectl-entry.py`).
  - Surfaced `bootstrapInSync`, `bootstrapReleaseId`, and `bootstrapSyncRequired` in health/update outputs while preserving `root/manager` rollback isolation, enabled committed shim upgrades, and swept empty `.bootstrap-stage-*` directories (`bootstrap_install.py`, `unified_health.py`, `release_commands.py`).
  - Raised `--initialize` backup token limits to `4096` chars to match `restore_current.py`, added bounded `keep=2` pruning for `sqlite-recovery-*` (`agent_storage.py`), fixed `management_lock` scoping/permissions (`configure_issuer.py`, `restore_current.py`), validated `usb.json` before `runtime-repair` receipts (`runtime_repair.py`), and cleaned stale `_spawned` entries (`service_manager.py`).
- **Cloud Worker & workstation helpers (`cloud/src/`, `tools/`):**
  - Aligned cached `Relay` response freshness (`30s` query / `1800s` set) in `google-home.ts` / `protocol.ts`, stopped `AuthStore.pollReport` from marking transient errors offline, preserved the `10s` alarm backoff on first report failure (`oauth-store.ts`), replaced the `Headers` secret comparison wrapper (`auth.ts`, `oauth-http.ts`), mapped invalid UTF-8 to HTTP `400`, deferred clearing `revoked` until `/v1/session` succeeds (`relay.ts`), added `--config` auto-detection in `tools/cloud-bootstrap.mjs`, and added a 128-bit X.509 `SerialNumber` in `tools/patch_cloudflared_hello_cert.py` (`requirements-router.lock.json` binary pin unchanged).
- **Live router acceptance & local test gates (`0.2.0-rc.16`):**
  - Workstation gates passed `91/91` portable Python tests (`562` total in `tests/`, including `141` Windows-skipped Linux/POSIX/root checks), `70/70` Cloudflare Worker Vitest tests + `tsc --noEmit`, `4/4` `cloud-bootstrap` Node tests, and `tools/check_publication.py`.
  - Refreshed `root/manager` (`state/bootstrap.json` `committed` at `0.2.0-rc.16`) via standalone `install_release.py` and activated `keenetic-hue-0.2.0-rc.16.huerel` via `/opt/bin/huectl update`; `huectl status --json` and `huectl health --live --json` passed (`healthy: true`, `releaseId: "0.2.0-rc.16"`, `bootstrapReleaseId: "0.2.0-rc.16"`, `bootstrapInSync: true`) with `agent`, `tunnel` (`4` ready connections), `manager`, `localApi`, and `ble` active and UTC timestamps observed in `agent.log`.
