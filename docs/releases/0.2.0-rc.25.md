## Changes Since 0.2.0-rc.24 and Verification

- **Bounded in-memory session sequence map (`hue_agent/journal.py`, `tests/test_journal_capacity.py`):**
  - Added `_MAX_SESSION_SEQUENCES = 256`, `_session_seq_ts`, and `_record_session_seq_locked()` so `Journal._session_sequences` evicts oldest inactive entries beyond `256` sessions and `_prune_memory_locked()` drops idle session entries older than `1800 s` while preserving the active `command.session_id`.
- **Pre-NTP startup timestamp clamping (`hue_agent/journal.py`, `tests/test_journal_capacity.py`):**
  - Clamped future `created` timestamps in `commands` and `sequences` (`UPDATE ... SET created=? WHERE created>?`) and capped loaded entries in `Journal.__init__()` so pre-NTP clock jumps backward after boot cannot trap stale records or session sequences in memory; loaded `sequences` inside the `1800 s` window in `ORDER BY created ASC` order (`test_pre_ntp_future_created_clamped_on_startup`, `test_session_sequences_bounded_and_pruned`).
- **Live router acceptance & local test gates (`0.2.0-rc.25`):**
  - Local gates verified `5/5` targeted journal capacity tests (`tests/test_journal_capacity.py`), `98/98` portable Python tests (`tools/run_portable_tests.py`: `failures: 0, errors: 0, skipped: 0`), and `tools/check_publication.py` (`errors: []`, `ok: true`).
  - Deterministic rebuild of `keenetic-hue-0.2.0-rc.25.huerel` from commit `a1713ae` matched the live router `verified-manifest.json` (`d8085a0592611173b6e646118e99a233c5ea398c2fffcf6a81272b6a3abac129`) and Ed25519 signature (`bootstrapInSync: true`), with live router health verified via `huectl status --json` and `huectl health --live --json` (`healthy: true`, `releaseId: "0.2.0-rc.25"`, `bootstrapReleaseId: "0.2.0-rc.25"`, `agent: "running"`, `tunnel: "ready"`, `manager: "running"`, `localApi: "ready"`, `ble: "ready"`).
