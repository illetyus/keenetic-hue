# 0.2.0-rc.15 — Release Security Hardening and Admin Reliability

**Status:** Release candidate that completed live router acceptance on the existing
personal installation on 10 November 2026.  
**Router package ID:** `0.2.0-rc.15` · **Signed release sequence:** `15` · **Commit:** `2c61cc1`

## Changes Since 0.2.0-rc.12 and Live Acceptance

- **`0.2.0-rc.13` (`1370c22`, 2026-11-09):** Enforced deterministic release metadata
  in `deploy/build_release.py` and `hue_admin/releases.py`, an explicit
  `PACKAGE_MODULES` allowlist in `deploy/build_release.py`, private token path
  validation in `hue_agent/cloud_link.py`, and `.github/dependabot.yml` pip tracking.
- **`0.2.0-rc.14` (`b90a923`, 2026-11-10):** Added publication secret filtering in
  `tools/check_publication.py`, non-POSIX `O_NOFOLLOW` compatibility guards
  (`getattr(os, 'O_NOFOLLOW', 0)`) in `hue_admin/` (`agent_storage.py`,
  `lifecycle_events.py`, `releases.py`, `service_manager.py`), and `.gitignore`
  hygiene updates.
- **`0.2.0-rc.15` (`2c61cc1`, 2026-11-10):** Resolved ten CLI, activation, and
  administrative hardening issues across `hue_admin/`:
  - Skipped starting a nonexistent previous service during activation recovery when
    no prior `active.json` slot existed (`activation.py`).
  - Allowed `-h` alongside `--help` in read-only CLI admission checks (`admission.py`).
  - Handled `KeyboardInterrupt` gracefully in backup/restore CLI handlers and required
    an interactive `stdin` TTY for `setup-code` (`cli.py`).
  - Bounded and pruned stale `.failed-`, `.replaced-`, and `.recovery-old-` release
    staging directories (`installation.py`).
  - Preserved `AttributeError` handling in lifecycle event status parsing
    (`lifecycle_events.py`).
  - Drained remaining unread child stdout bytes cleanly on exit while enforcing
    `OUTPUT_LIMIT` in `run_owned` (`owned_command.py`).
  - Enforced non-symlink private root-owned staging parent directory validation on
    Linux during backup restore staging (`restore.py`).
  - Enabled `pragma trusted_schema=OFF` and `pragma query_only=ON` during restore
    SQLite verification (`restore_current.py`).
  - Terminated partially spawned child processes and cleared stale `_spawned` entries
    when startup fails (`service_manager.py`).
- **Live acceptance (`0.2.0-rc.15`):** Verified the Ed25519 signature and activated
  `keenetic-hue-0.2.0-rc.15.huerel` on the Keenetic router; `huectl status --json` and
  `huectl health --live --json` reported `healthy: true` and
  `releaseId: "0.2.0-rc.15"` with zero crashes, unexpected restarts, or USB disconnects
  since activation on 10 November 2026. Post-`0.2.0-rc.15` uncommitted hardening
  recorded under `Unreleased` in [the changelog](../../CHANGELOG.md) is locally
  verified only and has not undergone router acceptance.
