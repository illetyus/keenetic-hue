## Changes Since 0.2.0-rc.19 and Verification

- **Unpredictable root-private `/tmp` directory handling in `hue_admin/storage_operation.py` (`tests/test_storage_operation.py`):**
  - Replaced the fixed `/tmp/hue-storage-operations` path in `start()` and `dispatch(['status', <uuid>])` with `tempfile.mkdtemp(prefix='hue-storage-operations-', dir=_tmp_base())` while preserving `RamJournal`'s `/tmp` (`tmpfs`) and `0o700` ownership constraints needed so offline storage maintenance does not hold open file descriptors under `/opt`.
  - Added `_find_operation_directory()` using `O_DIRECTORY | O_NOFOLLOW` / `lstat` checks to accept only root-owned `0o700` non-symlink directories and fail closed on ambiguous matches (`STORAGE_OPERATION_AMBIGUOUS`), with portable unit coverage (`test_start_default_root_uses_unpredictable_tmp_dir`, `test_find_operation_directory_enforces_root_private_non_symlink_dirs`).
- **TCP peer socket & process UID/GID verification for tunnel readiness (`hue_admin/health.py`, `hue_admin/unified_health.py`, `tests/test_health_peer.py`, `tests/test_unified_health.py`):**
  - Extracted shared `_verified_probe()` and added `verified_probe(port, path, pid, peer_guard=..., expected_uid=..., expected_gid=...)` in `hue_admin/health.py` so loopback HTTP readiness requests run only after verifying TCP socket ownership (`verify_tcp_peer`), process `Uid`/`Gid` rows (`verify_process_identity`), and `peer_guard()`.
  - Updated `hue_admin/unified_health.py` (`_component_identity` shared helper) so the `127.0.0.1:18790/ready` check validates `child_pid('tunnel')`, `child_owned('tunnel')`, and expected `hue-tunnel` UID/GID (`TUNNEL_OWNER_OR_READINESS_FAILED` on peer mismatch), and updated legacy `health.py` tunnel readiness probing to fail closed unless the supervised `tunnel` process is verified (`test_verified_probe_enforces_tcp_peer_and_process_identity`, `test_legacy_status_tunnel_probe_fails_closed_without_running_verified_peer`, `test_tunnel_readiness_verifies_peer_identity_and_degrades_on_spoof`).
- **Live router acceptance & local test gates (`0.2.0-rc.20`):**
  - Workstation gates on commit `bd0a799` passed `26` targeted tests (`24` passing, `2` POSIX root fixtures skipped on Windows), `91/91` portable Python tests (`tools/run_portable_tests.py`: `failures: 0, errors: 0, skipped: 0`), full `unittest discover` (`574` tests: `433` passing, `141` Windows-skipped native Linux/POSIX/root checks), and `tools/check_publication.py` (`errors: []`, `ok: true`).
