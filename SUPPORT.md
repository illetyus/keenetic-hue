# Support

Read [troubleshooting](docs/troubleshooting.md) first. For normal bugs, open a
GitHub issue with package version, Entware architecture, lamp/adapter model,
safe error code and reproduction steps. Distinguish physical observation from
an inferred status.

Do not paste full configuration, logs, SSH keys, BLE bonds, tokens, setup codes
or personal backups. Redact identifiers and personal paths. Use
[private reporting](SECURITY.md) for suspected vulnerabilities.

This is a personal integration with a narrow tested profile. Support is best
effort; no commercial support, universal hardware support or response time is promised.
